# Commande: start-session

Lis le fichier CLAUDE.md à la racine du projet pour comprendre l'architecture et les conventions de code de l'app mobile FitFlow.

## Instructions

1. Lis le fichier `CLAUDE.md` situé à la racine du projet
2. Confirme que tu as bien lu et compris le contenu en affichant "claude.md lu"
3. Tu es maintenant prêt à travailler sur l'app mobile FitFlow en respectant les conventions établies

## Contexte

Tu travailles sur l'application mobile de FitFlow, une plateforme de coaching fitness. L'app utilise:
- React Native avec Expo
- React Navigation pour la navigation (Stack + Bottom Tabs)
- Expo SecureStore pour le stockage sécurisé
- Axios et fetch pour les appels API
- Ionicons pour les icônes

Respecte les conventions de code françaises et la structure un écran = un fichier avec styles intégrés.
